# Audit of dhrubo.shop before the rebuild

Date: 2 November 2026. Live site observed at `https://www.dhrubo.shop` (commit of 6 Sep 2026). Evidence saved in the session scratchpad (`baseline/lh_mobile_before.json`, response headers, robots and sitemap captures).

## Verdict

The site was a visually ambitious single page that undersold a verifiable record and overstated an unverifiable one. It scored 59 on mobile performance, shipped 2.6 MB for one page, exposed no analytics, pointed to a GitHub account that returns 404, and told its own AI assistant nothing about Sahkarmi, the strongest project in the portfolio.

## Repository

| Item | Finding |
|---|---|
| Stack | Next.js 15.5.9, React 19, Tailwind 4, framer-motion, gsap (imported, unused) |
| Structure | One route (`/`), one API route (`/api/chat`), no tests, no CI, no docs |

## Technical SEO

- Canonical and sitemap used the apex host while Vercel redirects apex to `www` (308). Fixed: canonical host is `www`, sitemap has 22 URLs on that host.
- `robots.txt` contained a Yandex-only `Host:` line and no crawler policy. Replaced with the documented policy.
- One sitemap URL. Now every public route.
- No RSS, no `llms.txt`, no OG image route, no breadcrumbs. All added.
- JSON-LD: Person only. Now Person, WebSite, ProfilePage, WebPage, BreadcrumbList, SoftwareApplication (Sahkarmi), TechArticle.
- Google Search Console verification files existed in git history but not in the deployed `public/`; restored.

## Accessibility

Lighthouse 90. Failing: `button-name` (icon buttons without labels), `color-contrast`. Hero text was rendered by canvas animation, invisible to assistive technology until animation completed.

## Security

Only `strict-transport-security` was set. No CSP, no frame or content-type protections. The chat API had an in-memory rate limit, no schema validation and no prompt containment; it accepted arbitrary message roles.

## Analytics

No tag of any kind on the live site. Git history shows GA4 `G-1M1HKNCHYB` on the January 2026 static site; it was dropped in the September rewrite. Search Console and GA4 property state could not be inspected (no credentials); the DNS has no verification TXT.

## AI assistant

Groq `openai/gpt-oss-20b` with a static context string that predated Sahkarmi. Asked "What is Sahkarmi?" the live assistant could not answer. No retrieval, no citations, no token or time caps.

## Design

Dark-only, scrollytelling single page with a canvas frame scrubber, 3D bento tilt and a "live dispatch terminal". High effort, but every pattern was one the benchmark of 25 engineer sites found absent from the sites recruiters at AI labs actually reference. Nothing on the page was countable or clickable as proof.
